# EdaApp — правила проекта

Демо мини-приложения по детскому прикорму (6–36 мес). Сайт: https://besaneboy.github.io/edaapp/ (GitHub Pages из ветки `main`), открывается и в Telegram.

## Как вносить правки
- Всё приложение — один файл `index.html` (вёрстка, стили, скрипт). Сборщика и бэкенда нет.
- Фотографии блюд лежат в `img/`.
- При каждой правке увеличивай метку сборки: `const BUILD = "ДД.ММ · сборка N"` в `index.html` (дата правки, N + 1). По ней проверяют, не показывает ли Telegram старую версию из кеша.
- Сообщения коммитов — по-русски, коротко о том, что изменилось для пользователя.
- В начале работы подтяни свежий `main` (`git pull`): правки идут и с телефона, и с компьютера.

## Публикация
- Правка попадает на боевой сайт, когда оказывается в `main`.
- Ветки `claude/*` из облачных сессий автоматически вливаются в `main` (`.github/workflows/publish-mobile.yml`), так что достаточно закоммитить и запушить свою ветку. Если в workflow был конфликт, влей вручную.
- Сайт обновляется через 1–2 минуты после попадания в `main`.

## Данные
- Планер, история, профиль с фото и отметки «есть дома» хранятся в localStorage устройства (ключ `edaapp.planner.v1`), между устройствами не синхронизируются. Не меняй формат без миграции.
- Дневник введения продукта хранится в `state.intro` (продукт → старт, статус active/done/reaction, записи по дням). 3 дня «всё хорошо» — продукт введён (`state.tried`), сыпь/живот/стул — реакция и пауза 3 дня. Отметка — в планере, дорожка — во вкладке «Продукты» → «Путь прикорма».
- План ввода — `state.plan = {mode:"who"|"manual", list, dates}`. В режиме `who` порядок считается сам (чередование групп по ВОЗ, до 20 продуктов); любая ручная правка (порядок, удаление, добавление, дата) переводит в `manual`. Даты не хранятся: по 3 дня на продукт от конца текущего ввода, не раньше закреплённой даты и возраста.
- Данные справочника — учебные заглушки, перед релизом их заверяет педиатр.

## Скоуп
Только прикорм 6–36 мес: без импорта чужих рецептов и без подсчёта калорий взрослого.
Вкладки: Планер · Продукты · Рецепты · Покупки · Врачу.
